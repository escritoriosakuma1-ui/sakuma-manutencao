LEGENDA
Tipo separa máquinas (trator, colhedora, pulverizador autopropelido) de implementos (plantadeira, grade, carreta). O nome do equipamento vincula os itens de manutenção (Aba 2) e os registros das Abas 3 a 5 — ao renomear, todos os vínculos são atualizados automaticamente.
Os dados ficam salvos neste navegador. Use Exportar dados para gerar um arquivo de backup (.json).
